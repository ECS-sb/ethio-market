# የቴሌግራም ክትትል — አዘገጃጀት

ይህ ሲስተም የድርጅቱን የቴሌግራም አካውንቶች (የሽያጭ እና የተማሪዎች ምዝገባ) በ **Telegram Business** በኩል ከአንድ ቦት ጋር ያገናኛል።
እያንዳንዱ አዲስ መልዕክት በdatabase ይቀመጣል። ሰራተኛ ለደንበኛ የግል ስልክ፣ ሌላ የቴሌግራም አድራሻ፣ WhatsApp ወይም የድርጅቱ ያልሆነ የባንክ ቁጥር ሲልክ ማስጠንቀቂያ ይነሳል። መልዕክት ሲሰረዝም ማስጠንቀቂያ ይነሳል።
ከፍተኛ ማስጠንቀቂያዎች ወዲያውኑ ለባለቤቱ በቴሌግራም ይላካሉ። በየቀኑ ማታ 3:00 (21:00 የአዲስ አበባ ሰዓት) ደግሞ ሪፖርት ይላካል።

አድሚን ገጽ፦ `/admin/telegram`

## 1. ቦቱን መፍጠር

1. ቴሌግራም ላይ **@BotFather** ይክፈቱ፣ `/newbot` ብለው ይላኩ፣ ለቦቱ ስም ይስጡት። የሚሰጥዎትን **token** በሚስጥር ይያዙት።
2. በ @BotFather፦ `/mybots` → ቦትዎ → **Bot Settings** → **Secretary Mode** → **Turn on**። (በድሮው የቴሌግራም ስሪት ስሙ **Business Mode** ነበር።)

## 2. ተለዋዋጮች (env)

በ `.env.local` እና በ Vercel (Project → Settings → Environment Variables) ውስጥ ያስገቡ፦

| ስም | ምንድን ነው |
|---|---|
| `TELEGRAM_BOT_TOKEN` | ከ @BotFather የተገኘው token (ሚስጥር) |
| `TELEGRAM_WEBHOOK_SECRET` | ቢያንስ 32 ፊደል ያለው የዘፈቀደ ሚስጥር (A-Z, a-z, 0-9, _ -)። ለማመንጨት፦ `node -e "console.log(require('crypto').randomBytes(32).toString('base64url'))"` |
| `TELEGRAM_OWNER_CHAT_IDS` | ሪፖርትና ማስጠንቀቂያ የሚደርሳቸው የባለቤቶች chat ID፣ በኮማ የተለዩ። ለማግኘት ለቦቱ `/start` ይላኩለት። |
| `TELEGRAM_ALLOWED_CONTACTS` | የድርጅቱ የራሱ ስልኮች፣ የቴሌግራም ስሞች እና የባንክ/ቴሌብር ሂሳቦች፣ በኮማ የተለዩ። እነዚህ ሲላኩ ማስጠንቀቂያ አይነሳም። ለምሳሌ፦ `0911223344, @EthiocomputerSchool, 1000123456789` |
| `CRON_SECRET` | Vercel የዕለት ሪፖርቱን ሲጠራ የሚጠቀምበት ሚስጥር (እንደ webhook secret ያመንጩት) |
| `TELEGRAM_REPORT_LOCALE` | `am` (ነባሪ) ወይም `en` |
| `SITE_URL` | አማራጭ። በሪፖርቱ ውስጥ ላሉ ሊንኮች፣ ለምሳሌ `https://ethio-market.vercel.app`። ካልተሰጠ `BETTER_AUTH_URL` ይወሰዳል። |

> ⚠️ ማንም ሰው ለቦቱ `/start` ብሎ የራሱን chat ID ማግኘት ይችላል፤ ሪፖርት የሚደርሰው ግን `TELEGRAM_OWNER_CHAT_IDS` ውስጥ ላሉት ብቻ ነው።
> የሽያጭ አካውንቱ የራሱ chat ID አያስገቡ፤ ሰራተኞች ያዩታል። የእርስዎን የግል አካውንት ይጠቀሙ።

## 3. Database እና deploy

```bash
npm run db:migrate
```

ከዚያ ወደ Vercel deploy ያድርጉ (git push)።

## 4. Webhook-ን ማዘጋጀት

```bash
npm run telegram:setup -- https://YOUR-DOMAIN
```

`✓ Business Mode is on` እና `✓ Webhook set` ማሳየት አለበት።

## 5. አካውንቶቹን ማገናኘት (በእያንዳንዱ የድርጅት አካውንት)

1. አካውንቱ **Telegram Premium** ሊኖረው ይገባል።
2. **Settings → Telegram Business → Chatbots** (በአዲሱ ስሪት **Chat Automation** ሊባል ይችላል) → የቦቱን @username ያስገቡ።
3. የትኞቹን ቻቶች ማየት እንደሚችል ይምረጡ (ለምሳሌ "All 1-to-1 chats")። መልዕክት ለማንበብ እና ለመመለስ ፈቃድ ይስጡት።

## 6. የአንድ ሰዓት ሙከራ (አስፈላጊ)

1. ከሌላ ስልክ ለድርጅቱ አካውንት መልዕክት ይላኩ።
2. ከድርጅቱ አካውንት ይመልሱ። በመልሱ ውስጥ የሙከራ ስልክ ቁጥር ይጻፉ (ለምሳሌ `0900000000`)።
3. ያንን መልዕክት ይሰርዙት።
4. `/admin/telegram` ይክፈቱ፦
   - "የሰራተኛ መልዕክቶች" ቁጥር ከ0 በላይ ከሆነ ቴሌግራም ሰራተኞች የሚልኩትን መልዕክት ለቦቱ ይልካል ማለት ነው። ✓
   - "ስልክ ቁጥር ተልኳል" እና "መልዕክቶች ተሰርዘዋል" ማስጠንቀቂያዎች መታየት አለባቸው፤ ለእርስዎም በቴሌግራም መድረስ አለባቸው።

የሰራተኛ መልዕክቶች ቁጥር 0 ሆኖ ከቀረ፣ ቴሌግራም የባለቤቱን መልዕክቶች ለቦቱ አይልክም ማለት ነው። ያን ጊዜ ወደ "Team Inbox" (ሰራተኞች በዚህ ዌብሳይት በኩል የሚመልሱበት) እንሸጋገራለን።

## 7. ሽያጭን በAI መለየት (Claude)

Claude ቻቶቹን አንብቦ ሽያጮችንና ምዝገባዎችን ያወጣል። ደንበኞች የሚልኩትን የክፍያ ደረሰኝ (ፎቶ ወይም PDF) ያነባል፣ ገንዘቡ ወደ ድርጅቱ ሂሳብ መግባቱንም ያረጋግጣል።

- **ደረሰኝ ሲመጣ፦** ወዲያውኑ ይነበባል። ወደ ድርጅቱ ያልሆነ ሂሳብ ከተከፈለ (🔴 "ወደ ድርጅቱ ያልሆነ ሂሳብ ተከፍሏል")፣ ወይም አንድ ደረሰኝ (ተመሳሳይ transaction ID) ሁለት ጊዜ ከቀረበ (🔴) ማስጠንቀቂያ ይላካል። ከዚያ ያ ቻት ይተነተናል።
- **በየቀኑ 20:30 (የአዲስ አበባ ሰዓት)፦** አዲስ መልዕክት ያላቸው ቻቶች ይተነተናሉ፤ ውጤቱ በ21:00 ሪፖርት ውስጥ ይገባል።
- **AI ሽሽጥ ሲጠረጥር፦** "AI፦ ሽሽጥ ሊሆን ይችላል" የሚል (መካከለኛ) ማስጠንቀቂያ ይነሳል። ለምሳሌ ስልክ ቁጥር በፊደል ሲጻፍ ወይም "በቀጥታ ክፈልኝ" ሲባል።
- **አድሚን ገጽ፦** `/admin/telegram/sales` (ሽያጮች፣ ምዝገባዎች፣ ክፍያዎች) እና በእያንዳንዱ ቻት ገጽ ላይ የAI ማጠቃለያ።

### ማዘጋጀት

1. **console.anthropic.com** ይግቡ። በ **Billing** ገንዘብ ያስገቡ (ዓለም አቀፍ ካርድ ያስፈልጋል)። ከዚያ **API Keys → Create Key** ይጫኑ።
2. key-ን ይቅዱ (አንድ ጊዜ ብቻ ነው የሚታየው)። Vercel ላይ `ANTHROPIC_API_KEY` ብለው ያስገቡት፤ **Sensitive** ያብሩ።
3. **Deployments → ⋯ → Redeploy** ያድርጉ።

| ስም | ምንድን ነው |
|---|---|
| `ANTHROPIC_API_KEY` | ከconsole.anthropic.com የተገኘ key (ሚስጥር)። ከሌለ የAI ክፍሉ ዝም ብሎ አይሰራም፤ ሌላው ሲስተም ግን ይቀጥላል። |
| `TELEGRAM_AI_MODEL` | አማራጭ። ነባሪው `claude-haiku-5-5` (ርካሹ)። ደረሰኞች በትክክል ካልተነበቡ `claude-opus-5-5` ማድረግ ይቻላል፤ ጥራቱ ከፍ ይላል፣ ግን በግምት 40 እጥፍ ይወደዳል። |
| `TELEGRAM_COMPANY_NAMES` | አማራጭ። በደረሰኝ ላይ የሚታዩ የድርጅቱ ስሞች፣ በኮማ የተለዩ። ነባሪው፦ `Ethio CS, Ethio Computer School, ECS` |

### ማወቅ ያለብዎት

- **ወጪ፦** በነባሪው `claude-haiku-5-5` አንድ ደረሰኝ በግምት $0.0006፣ አንድ ቻት በግምት $0.001 ያስወጣል። በቀን 30 ቻትና 10 ደረሰኝ ከሆነ በወር ከ$1.5 በታች ይሆናል፤ የመጀመሪያው $5 ለብዙ ወራት ይበቃል። በ`claude-opus-5-5` በወር በግምት $45–60 ይሆናል። ትክክለኛውን ወጪ በconsole.anthropic.com → Usage ማየት ይቻላል። የVercel logs ደግሞ ለእያንዳንዱ ጥሪ የtoken ብዛት ያሳያሉ (`telegram ai …`)።
- **ግላዊነት፦** የደንበኞች ቻቶችና የደረሰኝ ምስሎች ለመተንተን ወደ Anthropic API ይላካሉ። Anthropic በAPI የሚላክ መረጃን በነባሪ ሞዴሉን ለማሰልጠን አይጠቀምበትም።
- **ትክክለኛነት፦** AI ሊሳሳት ይችላል። ሪፖርቱ አመላካች ነው፤ አስፈላጊ ሽያጮችን በቻቱ ውስጥ ያረጋግጡ።
- Opus ወይም Sonnet ከተመረጠ፣ Claude ጥያቄውን ካልተቀበለ (refusal) በሌላ ሞዴል በራሱ እንደገና ይሞከራል (server-side fallback)። Haiku ይህ አማራጭ የለውም፤ ያልተቀበለው ደረሰኝ ወይም ቻት ዝም ብሎ ይዘለላል።
